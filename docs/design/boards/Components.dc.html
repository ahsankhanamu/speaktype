Components

Every control, every state. Built on bits-ui (shadcn-style, composable). Capsules everywhere: 32 pt in panels and toolbars, 28 pt inside settings rows.

Buttons

One primary per view. Secondary for everything else. Plain for in-text actions. Destructive = a normal button with a red label (as macOS does), never filled red and never the default; say Delete when something is destroyed, Remove when it only leaves a list.

Behaviour: colour changes ease over 120 ms; pressed is one step darker with no movement (macOS buttons don't shift); the cursor stays an arrow, as on macOS; focus ring only for keyboard focus; disabled is 40% opacity, ignores hover and press, and keeps its label readable. Buttons on this board respond for real in Play mode.

Delete this session?

Its marks, audio and prompt are deleted from this Mac. This can't be undone.

Irreversible actions (delete a session, clear all history, reset permissions) confirm in an alert where Cancel is the default (blue, Return) and Delete is red. Undoable ones (delete a mark, remove a clip) happen at once with an Undo toast and no alert.
