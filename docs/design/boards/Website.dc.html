Questions

Does it work in every app?

Anywhere you can type: browsers, editors, terminals, chat apps. If there's nowhere to paste, SpeakType copies it for you instead.

Which coding agents can use what I send?

Any that can read image files — Claude Code, Cursor, opencode, Codex, Gemini CLI — plus chat apps like ChatGPT and Claude.

Will drawing get in my way?

No. You only draw while holding a key. Let go and your Mac behaves exactly as usual.
