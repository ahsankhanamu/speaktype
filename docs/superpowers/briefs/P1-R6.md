# Brief P1-R6: the model server never outlives SpeakType; people can unload it

**Read `_common.md` first.** Owner model: DeepSeek-V4.1-Flash. Worktree branch: `ws/P1-R6`.

**Why:** the owner found an orphaned `whisper-server` (large-v3, about 3.3 GB RSS) alive two days after quitting SpeakType. Owner's words: "stop the model process etc, and let the user do that too, also closing the app should close the model server too".

Today a normal quit kills the child (`lib.rs` `RunEvent::Exit` → `server::stop_server`). Orphans come from crashes, force-quit, SIGTERM (logout, `kill`), and dev rebuilds.

## Do, each with a test (pure logic tested; real-process checks listed in the report for me)

1. **Reap on launch.**
   - **Pidfile:** on spawn, write `<config>/whisper-server.pid` holding the pid and the spawn's start time. Remove it in `stop_server`.
   - **Startup check:** before choosing a port, if the pidfile names a live process, verify it before acting. Use `proc_pidpath` or `ps -o command=` and check that its executable is our bundled `whisper-server`. Only then send SIGTERM, wait up to 2 s, then SIGKILL.
   - **Never kill an unrelated process.** A reused pid must not be killed. Compare the executable path and that the process started at or before the recorded time.
   - Log one line.
   - Pure tests:
     - `reap_decision` for: no pidfile; a dead pid; a live pid with a different executable (leave it); a live whisper-server (reap it).
     - Pidfile round trip, in the test temp config dir.
2. **Signals.** Handle SIGTERM, SIGINT and SIGHUP (e.g. `signal-hook`, or Tauri's own handling if it exists): stop the server, then exit. Add a one-line reason for any new dependency.
3. **The server dies with its parent.** Spawn the sidecar with a parent watch, so a crash or force-quit never leaves it running.
   - Preferred: a tiny watchdog thread in the server-supervision code is not enough, because it dies with us. So use a POSIX approach:
     - put the child in its own process group, and register a kqueue `NOTE_EXIT` watch in a small helper; or
     - if that's heavy, launch through `/bin/sh -c 'exec …'` with the parent pid passed in, plus a watcher loop that kills the child when the parent pid disappears.
   - Pick the simplest robust one and justify it in the report.
   - Test the watcher logic with a fake.
4. **"Unload speech model"** for people.
   - **Menu bar:** add an item between "Paste last dictation again" and "History…". It reads "Unload speech model · frees ~3 GB" (use the loaded model's size from the catalog), or "Speech model not loaded" (disabled) when stopped.
   - **Settings → Advanced:** the existing server stop/restart becomes **Unload model / Load now**, with the same copy.
   - **When unloaded:** the next dictation loads it lazily. The existing `load_model_for_dictation` path shows "Getting ready…".
   - Add a command `unload_model() -> Result<(), IpcError>` if no current command does exactly this. It emits the existing server status events, so the widget dot and the Advanced page update.
5. **Quit is always clean.** The tray Quit and ⌘Q both call `stop_server` before exiting. Verify `RunEvent::ExitRequested` and `Exit` both reach it.
